# Framework Reporting Checklist

Ten items a report should satisfy when it uses the CRI, so that a score is
interpretable and the framework is testable rather than merely adopted.

1. **Instrument version.** State the version of the instrument and codebook used.
2. **Setting.** Describe the hospital or system (size, service mix) without identifying it.
3. **Who scored.** State the assessor's role and whether scoring was independent.
4. **Evidence basis.** List the artefacts substantiating every score of 5.
5. **Scores.** Report all twelve indicator scores, not only the composite.
6. **Composite.** Report the weighted composite to one decimal place.
7. **Floor rule.** State whether any indicator was 0 and, if so, the capped level.
8. **Maturity.** Report the maturity level and its cut-point band.
9. **Sensitivity.** Report the sensitivity of the composite to a 0.10 weight shift.
10. **Limits.** State that the index is proposed rather than validated, and note any
    deviation from this codebook.
